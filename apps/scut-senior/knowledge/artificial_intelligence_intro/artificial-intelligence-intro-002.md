第1章 绪论

1. 人工智能、机器学习、神经网络的区别与联系 ⭐⭐⭐

人工智能(AI)：最宏观的概念，研究如何让机器具有智能、模拟人类智能行为的学科。

机器学习(ML)：AI 的一个子领域，研究让计算机从数据中自动学习规律、实现自我完善的方法。

神经网络(NN)：机器学习中的一类具体模型/方法，模仿生物神经系统结构。

关系：三者是逐层包含关系 AI ⊃ ML ⊃ NN。深度学习是使用深层神经网络的机器学习。

2. 符号主义与连接主义的主要区别 ⭐⭐⭐

符号主义：认为智能来源于对符号的逻辑运算，基于知识和规则进行推理（如专家系统、逻辑推理）。核心是"物理符号系统假设"。可解释性强。

连接主义：认为智能来源于大量神经元的连接与并行计算，通过数据训练调整连接权重（如神经网络）。擅长感知类任务，黑盒性强。

（今年补充行为主义：认为智能源于智能体与环境的交互和反馈，强调感知-动作，如强化学习、机器人控制。）

3. 物理符号系统 vs 人工神经网络系统的差别

物理符号系统：以离散符号为基本单元，串行逻辑运算，知识显式表示，可解释。

人工神经网络：以神经元为单元，连续数值、并行分布式计算，知识隐式存于权重，不易解释。

4. 归纳推理 vs 演绎推理（jk2 新增）

演绎推理：从一般到特殊，前提为真则结论必然为真（如三段论、归结推理）。

归纳推理：从特殊到一般，由个别事例归纳出普遍规律，结论具有或然性（机器学习本质是归纳）。

第2章 知识工程

5. 知识表示方法有哪些？各自的表示形式 ⭐⭐⭐

谓词逻辑表示法：用一阶谓词公式表示，如 ∀x(Man(x)→Mortal(x))。

产生式表示法：用 IF-THEN 规则表示，如 IF 发烧 AND 咳嗽 THEN 感冒。

框架表示法：用槽(slot)和值组成的结构化框架表示，如"汽车"框架含颜色、品牌槽。

语义网络：用节点表示概念、有向弧表示关系（ISA、AKO 链）。

知识图谱：以结构化形式描述实体、概念及其关系的大规模语义网络。

6. 逻辑表示法的优缺点

优点：严密精确、自然（接近自然语言）、易于逻辑演绎推理、便于机器实现。

缺点：表达效率低、不便表示不确定性/模糊知识、易产生组合爆炸、难以表示过程性和启发性知识。

7. 产生式系统中推理机的推理方式 ⭐⭐

正向推理（数据驱动）：从已知事实出发，匹配规则前件，推出结论，直到达到目标。

反向推理（目标驱动）：从目标假设出发，反向寻找支持它的证据/规则。

双向推理：正反向结合，从两端向中间推进，提高效率。

8. 推理的三个层次（jk2 新增）

关联推理（相关关系）→ 干预推理（做某动作的效果）→ 反事实推理（如果当初…会怎样）。这是因果推理的三个层次（Pearl 因果阶梯）。

第3章 确定性推理

9. 简述反演法（归结反演）求取某个问题答案的过程 ⭐⭐⭐

1. 把已知前提用谓词公式表示，并化为子句集 S。

2. 把待求解的问题的否定用谓词公式表示，用一个求解谓词 ANSWER 附加到其上，化为子句加入 S（构造带 ANSWER 的重言式）。

3. 对新子句集反复应用归结原理进行归结。

4. 当归结出的子句只含 ANSWER 谓词时，ANSWER 中的项就是问题的答案。

（若只是证明命题：将结论取反加入子句集，归结出空子句 □ 即证明结论成立。）

第4章 不确定性推理

10. 不确定性推理的"不确定性"主要表现在哪些方面 ⭐⭐

证据的不确定性：观测数据可能有误差、不完整（如传感器噪声）。

知识（规则）的不确定性：规则本身是经验性的、非绝对（如"发烧多半是感冒"）。

推理过程/结论的不确定性：不确定性沿推理链传播、组合，导致结论不确定。

11. 什么是不确定性推理？需解决的基本问题 ⭐⭐

定义：在证据和知识都不完全确定的情况下，运用不确定性知识进行的推理。

基本问题：①不确定性的表示（证据与规则如何度量）；②不确定性的传递/传播（前提→结论如何算）；③不确定性的合成（多条规则支持同一结论如何合并）；④
结论的不确定性更新与决策。

12. 什么是贝叶斯定理？解决什么问题？刻画因果还是相关？ ⭐⭐⭐

公式：P(H|E) = P(E|H)·P(H) / P(E)。

解决问题：由易统计的先验概率 P(H) 和似然 P(E|H)，求难以直接统计的后验概率 P(H|E)（逆概率问题）。例如由 P(咳嗽|支气管炎) 求 P(支气管炎|咳嗽)。

刻画的是相关关系，不是因果关系（贝叶斯定理只反映变量间的概率相关，不能确定因果方向）。

第5章 搜索与优化

13. 回溯搜索策略和图搜索策略的区别 ⭐⭐

回溯搜索：深度优先思想，沿一条路径试探，失败则回退换路；一般不记录已访问全部节点，可能重复搜索、可能陷入死循环。

图搜索：用 OPEN 表和 CLOSED 表记录待扩展和已扩展节点，避免重复访问同一状态，能处理有环图，保证系统性和完备性。

14. AI 中的搜索 vs 数据库检索的差异

搜索：解不是预先存好的，需在状态空间中通过扩展节点动态"生成/构造"路径，关注路径与代价。

数据库检索：数据已存储，按索引精确匹配查询，直接取出，不涉及状态转移和路径代价。

15. 启发函数的可容性与一致性（jk2 新增）⭐⭐

可容性(admissible)：对任意节点 n，h(n) ≤ h(n)（h 为到目标的真实最小代价），即启发函数从不高估。可容 ⇒ A* 找到最优解。

一致性/单调性(consistent)：对任意相邻节点 n、n'，h(n) ≤ c(n,a,n') + h(n')，且 h(目标)=0（三角不等式）。一致 ⇒ 一定可容，且保证 f(n) 非递减，故每个节点首
次扩展即最优（无需重开节点）。

16. 评价函数与启发函数（补充）

评价函数 f(n)：搜索算法给每个候选节点打分的函数，每次扩展选 f(n) 值最优的节点。

直观：g(n) 是"已付成本"，h(n) 是"预估还需成本"，f(n) 就是经过 n 的路径的总估计代价。

第6章 机器学习

17. 机器学习中的"泛化"能力是指什么 ⭐⭐

指模型对训练时未见过的新数据做出正确预测的能力。泛化好说明模型学到的是数据背后的普遍规律，而非死记训练样本（避免过拟合）。

19. 聚类 vs 分类差异 + K-means 步骤 ⭐⭐

差异：分类有标签（监督），聚类无标签（无监督）。

K-means 步骤：①随机选 K 个初始质心；②将每个样本分配到最近的质心所在簇；③重新计算各簇均值作为新质心；④重复②③直到质心不再变化（收敛）。

K-means 特点：需预先指定 K；对初始值敏感；只能发现凸形（球形）簇；对噪声/离群点敏感。

20. 简述梯度下降算法的步骤 ⭐⭐

①初始化参数 θ；②计算损失函数对参数的梯度 ∇J(θ)；③沿负梯度方向更新 θ ← θ − α·∇J(θ)（α 为学习率）；④重复②③直到收敛（梯度趋近 0 或损失不再下降）。

21. DBSCAN 密度聚类的基本思想、过程与缺点 ⭐⭐

思想：基于密度，把足够高密度的区域划为簇。用两个参数：邻域半径 ε、最小点数 MinPts。核心点（ε 邻域内点数 ≥ MinPts）不断扩展相连的点形成簇。

过程：①任取未访问点，若其为核心点，建立新簇并把其密度可达的所有点纳入；②非核心点标记为边界点或噪声；③重复直到所有点被访问。

缺点：①对参数 ε、MinPts 敏感；②密度不均匀时效果差；③高维数据下距离度量失效（维数灾难）。

优点：无需指定簇数 K，能发现任意形状簇，能识别噪声。

22. 什么是交叉验证法？有什么用处 ⭐⭐

k 折交叉验证：将数据集分成 k 份，每次用 k−1 份训练、1 份验证，轮流 k 次，取平均性能。

用处：更充分利用有限数据，更可靠地评估模型泛化能力，减小因单次划分带来的偶然性，辅助模型选择与调参、防止过拟合。

23. 机器学习系统构成 + 结果可预测吗 + AI 风险 ⭐⭐

系统构成：数据采集与预处理 → 特征工程 → 模型（假设空间）→ 训练算法（优化目标）→ 评估/验证 → 部署预测，评估结果反馈调整。

是否可预测：基于数据驱动的机器学习是从数据中归纳规律而非死记数据；但结果不完全可预测——依赖数据质量、存在统计误差、黑盒模型决策不透明。

风险：数据偏见导致歧视性决策；黑盒不可解释导致责任难追溯；被恶意样本攻击；隐私泄露等。

24. 生成式方法 VS 判别式方法（jk2 新增）⭐⭐

生成式模型：学习联合概率分布 P(x,y)，再由贝叶斯求 P(y|x)。可生成新样本。代表：朴素贝叶斯、贝叶斯网络、HMM。

判别式模型：直接学习条件概率 P(y|x) 或决策边界。通常分类精度更高。代表：逻辑回归、SVM、决策树、神经网络。

区别：生成式建模数据如何产生（关注分布），判别式直接建模分类边界（关注区分）。

25. 监督学习 vs 强化学习（jk2 新增）

监督学习：从带标签的样本 (x, y) 中学习映射，有明确"正确答案"作监督信号。

强化学习：智能体通过与环境交互获得奖励信号（无逐样本标签），目标是学习使累积奖励最大的策略，反馈有延迟。

26. 深度学习 vs 传统机器学习（jk2 新增）

传统 ML：依赖人工设计特征，模型较浅，小数据可用。

深度学习：用深层神经网络自动学习特征（端到端），需大数据和算力，在图像/语音/NLP 上表现更优，但可解释性差。

28. 马尔科夫决策过程(MDP)有哪些元素 ⭐⭐

五元组 (S, A, P, R, γ)：

S：状态集合；A：动作集合；

P：状态转移概率 P(s'|s,a)；R：奖励函数 R(s,a)；

γ：折扣因子(0≤γ≤1)，权衡当前与未来奖励。

满足马尔科夫性：下一状态只依赖当前状态和动作，与历史无关。

29. 强化学习的目标与基本过程 ⭐⭐

目标：学习一个最优策略 π*，使智能体从环境获得的累积（折扣）奖励期望最大。

目标函数：π* = argmaxₚ E[Σ_{t=0}^∞ γᵗ·r_t]。

基本过程：智能体在状态 s 下选动作 a → 环境给出奖励 r 和新状态 s' → 智能体据此更新策略 → 循环。核心是"状态-动作-奖励"的试错交互。

关键要素：

试错学习：智能体通过尝试不同动作、观察奖励来学习。

延时奖励：当前动作可能影响未来所有奖励（不同于监督学习的即时反馈）。

探索 vs 利用(exploration vs exploitation)：利用是选当前已知最优动作，探索是尝试新动作以发现更优策略；用 ε-贪心策略 / Softmax 策略平衡两者。

贝尔曼方程（强化学习的数学基础）：描述状态价值/动作价值的递归关系，最优策略使价值函数最大化：

V*(s) = maxₐ Σ P(s'|s,a)[R(s,a) + γ·V*(s')]。

第7章 神经网络与深度学习

30. BP 算法适用什么结构？描述学习过程 ⭐⭐⭐

适用结构：（多层）前馈神经网络（全连接前馈网络）。

学习过程：①前向传播：输入经各层加权求和+激活，逐层计算到输出；②计算输出与目标的误差（损失）；③误差反向传播：将误差从输出层向输入层逐层反传，

用链式法则求损失对各权重的梯度；④用梯度下降更新相邻层神经元之间的连接权重（和偏置）；⑤重复直到收敛。

31. 深度学习模型举例 + 应用

CNN 卷积神经网络 → 图像分类、目标检测。

RNN/LSTM 循环神经网络 → 语音识别、机器翻译、时序预测。

Transformer → 大语言模型、机器翻译。

（GAN → 图像生成；也可答）

SVM 支持向量机专题（确定考简答）⭐⭐⭐

S1. 支持向量机的优点在哪？用示意图解释结构风险最小化的含义与合理性 ★核心题★

SVM 的优点：

1. 基于结构风险最小化原则，泛化能力强，适合小样本。

2. 最终决策只由少数支持向量决定，模型稀疏、计算高效。

3. 通过核函数巧妙解决非线性分类，避免高维显式变换（避开维数灾难）。

4. 是凸二次规划问题，存在唯一全局最优解，不会陷入局部极小。

结构风险最小化(SRM)的含义（配示意图）：

真实（期望）风险 R(a) ≤ 经验风险 Remp(a) + 置信范围(与 VC 维/模型复杂度有关)。

经验风险：模型在训练集上的误差；置信范围：模型复杂度（VC 维）带来的泛化误差上界。

传统方法只最小化经验风险(ERM)，样本有限时不合理（易过拟合）。

SRM = 在保证经验风险较小的同时，控制模型复杂度（VC 维），使两者之和（真实风险上界）最小。

合理性：模型太简单→经验风险大（欠拟合）；太复杂→置信范围大（过拟合）。只有折中使总和最小，才能得到泛化能力最好的模型。SVM 通过最大化分类间隔

(Margin=2/‖w‖)来控制 VC 维，正是实现 SRM 的具体手段。

S2. SVM 相关概念速记

最优分类超平面：能无错误划分两类、且使两类中最近样本到超平面距离(分类间隔 Margin)最大的超平面。(w·x)−b=0。

分类间隔 Margin = 2/‖w‖，最大化间隔 ⟺ 最小化 ½‖w‖²（二次规划）。

支持向量：距离超平面最近、决定超平面位置的那些样本（对应拉格朗日乘子 aᵢ≠0 的样本）。

松弛变量 ξ 与惩罚因子 C：处理线性不可分，C 在最大间隔与误分之间折衷。

核函数：K(xᵢ,xⱼ)=Φ(xᵢ)·Φ(xⱼ)，把样本空间内积替换为核函数，隐式实现高维映射，避免显式非线性变换。常用：多项式核、径向基核(RBF)、Sigmoid 核。满足

Mercer 条件的函数即为核函数。
