# Sample_handwritten

<!-- page: 1 -->

https://developer.android.google.cn/codelabs/digit-classifier-tflite#0 Build a

handwritten digit classifier app with TensorFlow Lite (google.cn)

Follow the instructions to implement an Android app that can recognize handwritten

digits that you write.

If you do not want to train the TensorFlow Lite model by yourself, use the attached

TensorFlow Lite model file mnist.tflite. Follow the instructions from

https://developer.android.google.cn/codelabs/digit-classifier-tflite#2 to develop the

handwritten_Digits_Recognition Android application.
