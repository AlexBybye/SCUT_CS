三、计算题

21（10分）．

解法1：

由高斯定理可知空腔内*E*＝0，故带电球层的空腔是等势区，各点电势均为*U* *.*

在球层内取半径为*r*→*r*＋d*r*的薄球层．其电荷为

d*q*  =  **  4*r*2d*r*        3分

该薄层电荷在球心处产生的电势为

$dU=dq/\left ( {4{\pi \varepsilon }_{0}r}\right )=\rho rdr/{\varepsilon }_{0}$                  3分

整个带电球层在球心处产生的电势为

${U}_{0}=\int {dU}_{0}=\frac {\rho } {{\varepsilon }_{0}}\int rdr=\frac {\rho } {2{\varepsilon }_{0}}\left ( {{R}_{2}^{2}-{R}_{1}^{2}}\right )$           2分

因为空腔内为等势区所以空腔内任一点的电势*U*为

$U={U}_{0}=\frac {\rho } {2{\varepsilon }_{0}}\left ( {{R}_{2}^{2}-{R}_{1}^{2}}\right )$                          2分

$dI=\frac {I} {\pi R}dl$$=\frac {I} {\pi R}Rd\theta$$=\frac {I} {\pi }d\theta$           2分

$dB=\frac {{\mu }_{0}dI} {2\pi R}$$=\frac{\mu_0I}{2\pi^2R}d\theta$              2分

${dB}_{x}=-dBsin\theta$$=-\frac{\mu_0I}{2\pi^2R}\sin\theta\,d\theta$

${B}_{x}=-\int _{0} ^{\pi } \frac {{\mu }_{0}I} {2{\pi }^{2}R}sin\theta d\theta$ $=\frac {{\mu }_{0}I} {2{\pi }^{2}R}cos\theta {|}_{0}^{\pi }$$=-\frac {{\mu }_{0}I} {{\pi }^{2}R}$           2分
