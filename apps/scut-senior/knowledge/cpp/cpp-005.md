# 实践题一

（2）编辑时间：3’42”

（3）分析原因：第一组满足三角条件 出现：area=6

第二组不满足两边之和大于第三边 出现：area=-nan(ind)

第三组出现边长为0  出现：area=-nan(ind)

第四组出现边长为-2  出现：area=-0

解决方案：在原方案基础上套上一个if条件判断，来避免错误数据进入程序输出，具体如下：

#include<iostream>

#include<cmath>

using namespace  std;

int  main()

{

double  a, b, c, s, area;

while  (cin  >>  a  >>  b  >>  c) {

If((a+b>c)&&（a+c>b）&&（b+c>a）&&（a-b<c）&&（b-a<c）&&（a-c<b）&&（c-a<b）&&（b-c<a）&&（c-b<a))

{

cout  << "a,b,c=";

cin  >>  a  >>  b  >>  c;

s = (a + b + c) / 2.0;

area = sqrt(s * (s - a) * (s - b) * (s - c));

cout  << "area=" <<  area  <<  endl;

}

else

{cout  << "数值不符合要求" <<  endl;

}

}

return  0;

}

（4）改为int后：

第一组：不变，仍为area=6

第二组：变成area=-2147483648

第三组：变成area=-2147483648

第四组：变成：area=0

原因：1:由8bytedouble变成4byteint，可能在编译过程中出现了数据缺失现象

不可以，因为当仅s,area变成  double，会出现int型与double型的复制转换，而原代码没有强制转换。

2:sqrt函数返还数据为浮点型，用double更加合理接收。
