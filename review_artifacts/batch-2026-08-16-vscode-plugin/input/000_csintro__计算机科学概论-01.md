# 中国计算机软硬件发展历史

## 软件发展史：三轮跨越，从固定桌面到移动，从封闭到开源

中国由于建国时期处于优先发展重工业阶段，因此对于轻工业高科技IT行业起步较晚，而纵使起步虽晚，却在近五十年间弯道超车，实现软件的飞跃。

以下载类软件为例，上世纪八十年代，中国软件下载器（HTTP下载）催生了计划下载技术，在当时的条件下，成功推开了下载器大门。紧接着，如同上课对于早期计算机更迭所适用的**摩尔定律**一般，十年之后，1999年网络快车（MHT下载）又一次将市场洗盘，并顺理成章成了国内第一款打下全球市场的中国软件。又是十年之后，2011年互联网基础建设的进步，让中心化服务器的存储和带宽不成问题，网盘开始崛起，市场再次充满活力与无限可能。

个人以为，中国计算机软件历史基本上都经历了三代演变，即80年代后期初步形成雏形，90年代后期基本建成体系，00年代后期跻身世界领先水平。

## 硬件发展史：四代风雨征程，甲子见证奇迹

早在1947～1948年，华罗庚教授心里已经开始盘算着回国后也要在中国开展电子计算机的研制工作。他回国后从清华大学电机系物色了闵乃大、夏培肃和王传英三位科研人员在他任所长的中国科学院数学所内建立了中国第一个电子计算机科研小组任务就是要设计和研制中国自己的电子计算机。毛主席和周总理深谋远虑，十分赞同。终于在那个独特的历史年代里，闵大可教授率队赴苏考察，得到了弯道超车的机会。根据苏联提供的M-3机设计图纸局部修改，在专家的指导下，中科院计算所完成了我国第一台小型电脑的建设，后改名为103型计算机，运算速度只有每秒几十次，后来安装了自行研制的磁心存储器**（从上课内容不难发现其实中国计算机似乎并没有经历magnet drum 的时期，似乎中国电子计算机研制起步比美国整整晚一代）**，将速度提升到3000次每秒。而我国在研制第一代电子管计算机的同时，已开始研制晶体管计算机，并于1965年研制成功的我国第一台大型晶体管计算机。但由于**文革**等历史原因，1977年4月，清华大学方研制成功我国第一台微型四代计算机。**改革开放**后，计算机发展可谓是百花齐放，终于在新时代赶上国际潮流。

总的来讲，中国计算机硬件经历了四代发展，而我们的研制水平与国外的差距在逐步缩小。包括本人现在使用的联想Y9000P，都足以证明中国计算机软硬件其实已经与国际接轨，作为新一代IT人员，我们应接过前辈的接力棒，迎心积力再进发，为建设大国IT付出不懈努力！
